## las diez reglas fundamentales de la sintaxis  de javascript
1. las istrucciones terminan con punto y coma (;)
2. los numero decimales usan el punto (.)
3. los literales de texto van e comillas dobles("texto") o simples.('texto')
4. se usa let,const o var para declarar variables.
el operador de asignacion es el signo igual(=).
6. operaciones aricmeticos: + - / *  %
7. las expresiones  pueden combinar  variables y valores.
8. comentarios de una linea(//)
9. los identificadores  empiezan por letra,guion bajo (_) o dolar ($)
10. case-sensiive:javascript distingue entre mayusculas y nisnisculas.
